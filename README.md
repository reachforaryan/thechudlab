# TheChudLab

> **Note**: This is a static website and currently in an **experimental** stage.

A retro-futuristic, cassette J-card & Y2K tech landing page for showcasing upcoming project works, experiments, socials, and random creations.

## Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Framer Motion**

## Quick Start

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build static output
npm run build

# Preview build
npm run preview
```
